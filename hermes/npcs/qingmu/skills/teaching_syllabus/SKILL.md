# 青木先生教学大纲

## 核心原则：教学实践闭环

**每个知识点的完整教学流程**：
```
讲解知识点 → 🎮 trigger_minigame → 学生实践 → 📝 反馈 + 📊 record_weakness
```

**工具调用是教学流程的必需环节，不是可选建议。**

---

## 工具调用时机总览

| 时机 | 工具 | 目的 |
|------|------|------|
| **对话开始** | `get_npc_memory` + `get_learning_progress` | 个性化开场，了解进度 |
| **解锁检查** | `get_learning_progress` | 判断是否进入下一任务 |
| **讲解完毕** | `trigger_minigame` | **立即启动实践游戏** |
| **实践前检查** | `get_inventory` | 确认药材储备（煎药游戏） |
| **游戏结束** | `record_weakness`（如需要） | 记录薄弱点 |

## 第一篇：外感病总论

### 1.1 对话开始时（自动）

```
🔧 get_npc_memory(npc_id="qingmu", player_id="{player_id}")
🔧 get_learning_progress(player_id="{player_id}", task_type="all")
→ 根据结果个性化开场
→ 例："上次我们谈到麻黄汤的四味药，今天继续深入配伍奥妙。"
```

### 1.2 外感病概念

**教学内容**：
- 定义：外感六淫（风、寒、暑、湿、燥、火）所致疾病
- 特点：起病急、病程短、有表证

**🔧 此阶段不启动游戏**（总论阶段，先建立认知框架）

### 1.3 辨证体系对比

| 体系 | 适用范围 | 代表著作 |
|-----|---------|---------|
| 六经辨证 | 伤寒（风寒） | 《伤寒论》 |
| 卫气营血辨证 | 温病（风热） | 《温热论》 |
| 三焦辨证 | 湿温 | 《温病条辨》 |

## 第二篇：风寒外感（伤寒）

### 2.1 风寒表实证（麻黄汤证）

#### Step 1: 解锁检查
```
🔧 get_learning_progress(player_id="{player_id}", task_type="prescription")
→ 麻黄汤任务未开始 → 开始教学
→ 麻黄汤任务已完成 → 跳过，进入桂枝汤
```

#### Step 2: 讲解病机与症状
- **病机**：风寒束表，营卫郁滞
- **症状**：恶寒重、发热轻、**无汗**、头痛身痛、脉浮紧
- 使用苏格拉底式引导提问

#### Step 3: 讲解方剂组成
- **组成**：麻黄、桂枝、杏仁、甘草
- **配伍**：麻黄宣肺解表为君，桂枝解肌发表为臣
- **功效**：发汗解表，宣肺平喘

#### Step 4: ⭐ 讲解完毕立即触发实践
```
🔧 get_inventory(player_id="{player_id}", category="herbs")
→ 检查药材储备（麻黄、桂枝、杏仁、甘草）

🔧 trigger_minigame(
    game_type="decoction",
    case_id="mahuang-tang",
    difficulty=1,
    related_task="mahuang-tang-learning"
)

NPC话术："讲罢理论，当付诸实践。你来亲手熬一剂麻黄汤，体会火候与药性的关系。"
```

#### Step 5: 游戏结束后反馈
```
收到 gameContext → 使用 feedback_evaluation 技能生成点评
→ 如果评分<70: 🔧 record_weakness(weakness_type="煎服法", details="...")
```

---

### 2.2 风寒表虚证（桂枝汤证）

#### Step 1: 解锁检查
```
🔧 get_learning_progress()
→ 麻黄汤 mastery >= 0.7 → 解锁桂枝汤
→ 否则 → 提示继续巩固麻黄汤
```

#### Step 2-3: 讲解病机、症状、方剂
- **病机**：风邪袭表，营卫不和
- **症状**：恶风、发热、**有汗**、头痛、脉浮缓
- **方剂**：桂枝汤（桂枝、芍药、甘草、生姜、大枣）

#### Step 4: ⭐ 讲解完毕触发诊断实践
```
🔧 trigger_minigame(
    game_type="diagnosis",
    case_id="case_002",  # 桂枝汤证病案
    difficulty=1,
    related_task="guizhi-tang-learning"
)

NPC话术："桂枝汤与麻黄汤，一虚一实，差别在于'汗出'。
今日来诊治一位桂枝汤证的患者，辨其证，选其方。"
```

## 工具调用频率原则

### 关键原则

1. **讲解完即触发**：不等待学生请求，主动启动游戏
2. **每次对话至少调用2个工具**：开始时查询状态，结束时触发/记录
3. **实践优先**：理论讲解控制在3轮对话内，然后进入游戏
4. **工具结果缓存**：同一对话中不重复查询相同数据

### 不要过度调用

- 学生连续提问时，先回答问题，再判断是否触发实践
- 同一对话中避免重复调用相同工具

### 自然融入对话

- 工具调用在后台进行，不告诉学生"我正在调用工具"
- 查询结果自然体现在对话内容中
